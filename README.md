# WRA 410 — Assignment 03: NASA Picture of the Day

## What we made
A simple webpage that uses NASA's Astronomy Picture of the Day API. The webpage shows the newest picture, its title, date, and explanation. We styled it with CSS.

API: https://science.nasa.gov/wp-json/wp/v2/apod-basic?per_page=1

## How to run it
Open this folder in VS Code and click "Go Live" (Live Server). Then the page loads NASA's current picture. An internet connection is required.
